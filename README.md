# ClubOps AI

AI-powered event and club operations platform for college clubs.

## Problem / Motivation

College clubs struggle to manage events, tasks, volunteers, meeting notes, and announcements across multiple disconnected tools. This leads to poor coordination, missed deadlines, and lost institutional knowledge.

## Planned Solution

ClubOps AI consolidates all club operations into a single platform with AI assistance for:
- Meeting note analysis and action item extraction
- Automatic risk identification
- AI-generated announcements
- Centralized club knowledge repository

## Features (Planned)

- Event creation and management
- Task management with assignments
- Volunteer management
- AI-powered meeting note analysis
- Automatic extraction of action items, owners, and deadlines
- Risk identification
- AI-generated announcements
- Basic club knowledge/document repository
- Event operations dashboard

## Tech Stack

- **Frontend:** React + Vite + Tailwind CSS
- **Backend:** Python + FastAPI
- **Database:** SQLite
- **AI:** LLM-based integration
